**Tagline:** Provision CyberPanel services from PeltyCMS orders

## CyberPanel provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on CyberPanel when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable CyberPanel API/panel
- API token or login configured in Pelty
